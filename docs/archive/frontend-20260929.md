# Historical frontend — 29 September 2026

Archived on 8 October. Race, fictional examples and the fixed publication described below are retired. See `../frontend.md` for current routes.

Implemented locally on 2026-09-29. No hosted deployment, database mutation, model inference, collection run or automatic validation is part of this frontend change.

## Interface

Compact top navigation, restrained navy/slate styling, responsive layouts and table-led research. A real COBE globe, adapted from 21st.dev, opens the annual briefing with country coverage, reviewed evidence and net-zero commitment lenses. Evil Charts/shadcn components provide patterned comparisons. Both renderers load on demand. See [component sources and adaptation boundaries](component-sources.md). No sidebar, chatbot, authentication, external fonts or tracking services are introduced.

| Route | Purpose |
| --- | --- |
| `/` | Annual briefing, interactive country globe and three evidence-aware lenses; calculated benchmark coverage, active-universe counts, sector cohort medians, Scope 3 coverage, renewable adoption, disclosure completeness and numeric extremes. |
| `/companies` | Case-insensitive name/ticker/domain search, AND-combined sector/country filters, 20-row pagination, customisable columns and comparison selection. Column preferences alone persist in browser storage. |
| `/companies/:id` | Benchmark position, emissions, energy, targets, disclosure quality, governance, prototype components and source reports. Every metric has a source action, including missing evidence. |
| `/compare` | Select two to five companies, inspect a side-by-side evidence table and compatible grouped charts. Selection survives navigation but not a full reload. |
| `/race` | Arcade-inspired top-down cars, peer-relative exhaust, detailed evidence and equivalent table/list. Overall positions require explicit eligible engine ranks; the current live ranking gate stays disabled. Separate, opt-in fictional demo. [Mappings and limitations](sustainability-race.md). |
| `/trends` | Separate comparable sector cohorts, medians, annual change and eligible evidence coverage. No invented multi-year time series. |
| `/methodology` | Source collection, local extraction, validation gates, conversions, percentile formula, prototype weights and limitations. Usable without a backend connection. |
| `/admin/reports` | Existing read-only acquisition-quality view, unchanged. |

Company profiles additionally expose [structured peer-gap explanations](peer-gap-explanations.md) with source drawers and fingerprint-matched CSV/JSON exports. This section loads a read-only company explanation from the backend; it does not generate narrative or recompute peer statistics in the browser. The Race links to the full profile explanation. Missing, incomparable and insufficient-peer states remain explicit.

The `year` URL parameter is retained across navigation; default 2025 means observation year, not publication year. Browser history, direct route loads and modifier-click links are supported. Production hosting must return the SPA entry point for application routes and route `/api` to FastAPI.

## Data and source-of-truth contract

- Production reads `/api/companies?active=true` and `/api/benchmarks?year=…` in pages of 100, up to the current 500-company capacity. It loads the complete universe before calculating display counts; a first page is never presented as the total population.
- Typed runtime checks reject malformed responses, inconsistent company IDs, incomplete pagination and changing benchmark input fingerprints across pages. Aborted/year-superseded requests cannot overwrite current data.
- Values, eligibility decisions, peer sample sizes, medians, flags, formulas and prototype components come from the existing benchmark engine. The frontend does not validate extracted observations or recalculate rankings/medians.
- Overview coverage is explicitly the proportion of active companies with **eligible observations in this dataset**, not an assertion about all disclosures in the market. Benchmarked means at least one eligible peer percentile, not a composite ESG rating.
- Null and ineligible values remain missing. A real zero remains zero. Connection errors never substitute fixtures or cached findings from another reporting year.
- Globe pins use sourced country label coordinates, not headquarters or operating sites. Market selection links to the country-filtered company table. A decorative atmospheric halo is not ozone data. Target commitments are never labelled net-zero progress. Unsupported countries remain in the selector, explicitly unplotted.
- Default peer groups are sectors. Metric-level percentile controls identify the selected measure; higher percentile means larger, not inherently better. Peer sample size is displayed, including when the minimum is unmet.
- Charts require at least two eligible values per series with matching cohort keys and expected canonical units. Missing values are not plotted as zero. Renewable energy and renewable electricity remain separate series/denominators. Cross-sector raw comparisons may be displayed only when their measurement contexts match; their peer percentiles still refer to their own sector cohorts.
- The prototype score is secondary and labelled “Prototype benchmark score — not an external ESG rating.” Components, weights, coverage and evidence can be inspected. Live composite ranking remains disabled. Race's fictional demo is explicitly opt-in and never a failure/missing-data fallback; its source drawer states that no real report or validation decision exists.

### Source drawer

The drawer retains report title, physical page, excerpt, original value/unit, normalised value/unit, validation state, extraction method, audit attribution, notes and checksum. Derived metrics retain formulas and multiple input observations. Sector-median sources include every contributing company value and all underlying observations from the same API snapshot, with cohort definition, period and boundary.

Official report links accept only absolute HTTP(S) URLs without embedded credentials, preserve access to the original report and add a page fragment where available. Text is rendered as text, not HTML. A report substantiates the company's **reported claim**; validation is not independent assurance of actual environmental performance.

The modal has an accessible name, an inert background, focus trapping, Escape/backdrop closing, scroll locking and trigger-focus restoration. Keyboard outlines, skip navigation, table semantics, non-colour status text and reduced-motion rules are included. Wide data tables scroll inside their own container on small screens.

## Run locally

The backend needs an explicitly configured PostgreSQL database and migrations through `d40e179a21c6`. The frontend never starts PostgreSQL, migrates the schema or imports companies automatically. Use the existing database setup in the root README, then:

```bash
# Terminal 1, repository root: apply only to the intended configured database.
cd backend
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# Terminal 2, repository root:
cd frontend
npm ci
npm run dev
```

Open [local workspace](http://127.0.0.1:5173). Vite proxies `/api` to loopback port 8000 by default. Do not open `index.html` as a `file://` URL. Starting the frontend/API does not launch a pipeline or inference. Unreviewed evidence remains unreviewed; insufficient peer data legitimately produces empty views.
